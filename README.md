# 🛍️ فروشگاه اینترنتی (Django)

یک فروشگاه اینترنتی **دو زبانه** (فارسی / انگلیسی) با **تم دارک و لایت**، سبد خرید، درگاه پرداخت آزمایشی و **پنل مدیریت اختصاصی** که با همان ظاهر سایت ساخته شده است. بک‌اند با **Python** و **Django** نوشته شده است.

---

## ✨ امکانات

**فروشگاه**
- طراحی ریسپانسیو برای موبایل، تبلت و دسکتاپ
- تم **دارک** (مشکی، قرمز، سبز) و تم **لایت** (سفید، سبز و قرمز کم‌رنگ). انتخاب کاربر در مرورگر ذخیره می‌شود
- دو زبانه: فارسی (راست‌به‌چپ، فونت **وزیر**) و انگلیسی (چپ‌به‌راست، فونت **Fira Code**)
- انیمیشن‌های **AOS**
- بنر اسلایدر با دکمه‌های قبلی/بعدی، نقطه‌های راهنما و پخش خودکار
- دسته‌بندی‌ها: پوشاک، گوشی، تابلو (قابل افزودن و ویرایش از پنل) و جستجوی محصول
- ثبت‌نام و ورود با **ایمیل و رمز عبور** (رمزها هش‌شده ذخیره می‌شوند)
- سبد خرید: افزودن به سبد از هر محصول، تغییر تعداد، **انتخاب آیتم‌ها** و جمع قیمت آیتم‌های انتخاب‌شده به‌صورت زنده
- صفحه‌ی **درگاه پرداخت کاملاً آزمایشی** (هیچ مبلغی کسر نمی‌شود) و ثبت سفارش
- ویرایش پروفایل (نام، ایمیل، تلفن، آدرس) و لیست سفارش‌ها

**پنل مدیریت (`/panel/`)** ویژه‌ی ادمین
- داشبورد: کل فروش، فروش امروز، تعداد سفارش‌ها، میانگین سفارش، تعداد کاربران، کاربران جدید، بازدید امروز / ۷ روز / کل، بازدیدکننده‌ی یکتا، آنلاین‌ها، نمودار فروش و بازدید، پرفروش‌ترین‌ها
- مدیریت (افزودن، ویرایش، حذف، جستجو): کاربران، دسته‌بندی‌ها، محصولات، بنرها (عکس، عنوان، متن و مقصد دکمه) و سفارش‌ها
- گزارش بازدیدها و **فعالیت کاربران** (ورود، ثبت‌نام، سبد خرید، پرداخت و ...)
- پنل پیش‌فرض جنگو هم در `/admin/` در دسترس است

## 🚀 نصب و اجرا

پیش‌نیاز: **Python 3.10 یا بالاتر**

```bash
# ۱) (پیشنهادی) ساخت محیط مجازی
python -m venv venv
venv\Scripts\activate          # ویندوز
source venv/bin/activate       # لینوکس / مک

# ۲) نصب وابستگی‌ها
pip install -r requirements.txt

# ۳) ساخت دیتابیس
python manage.py migrate

# ۴) داده‌ی نمونه + حساب ادمین
python manage.py seed

# ۵) اجرا
python manage.py runserver
```

بعد این آدرس‌ها را باز کن:

| بخش | آدرس |
|---|---|
| فروشگاه | http://127.0.0.1:8000/ |
| پنل مدیریت | http://127.0.0.1:8000/panel/ |
| پنل پیش‌فرض جنگو | http://127.0.0.1:8000/admin/ |

> برای بارگذاری فونت‌ها، آیکون‌ها و انیمیشن‌ها به اینترنت نیاز است (CDN).
