# 🛍️ فروشگاه اینترنتی (Django)

یک فروشگاه اینترنتی **دو زبانه** (فارسی / انگلیسی) با **تم دارک و لایت**، سبد خرید، درگاه پرداخت آزمایشی و **پنل مدیریت اختصاصی** که با همان ظاهر سایت ساخته شده است. بک‌اند با **Python** و **Django** نوشته شده است.

---

## ✨ امکانات

**فروشگاه**
- طراحی ریسپانسیو برای موبایل، تبلت و دسکتاپ
- تم **دارک** (مشکی، قرمز، سبز) و تم **لایت** (سفید، سبز و قرمز کم‌رنگ). انتخاب کاربر در مرورگر ذخیره می‌شود
- دو زبانه: فارسی (راست‌به‌چپ، فونت **وزیر**) و انگلیسی (چپ‌به‌راست، فونت **Fira Code**)
- انیمیشن‌های **AOS**
- بنر اسلایدر با دکمه‌های قبلی/بعدی، نقطه‌های راهنما و پخش خودکار
- دسته‌بندی‌ها: پوشاک، گوشی، تابلو (قابل افزودن و ویرایش از پنل) و جستجوی محصول
- ثبت‌نام و ورود با **ایمیل و رمز عبور** (رمزها هش‌شده ذخیره می‌شوند)
- سبد خرید: افزودن به سبد از هر محصول، تغییر تعداد، **انتخاب آیتم‌ها** و جمع قیمت آیتم‌های انتخاب‌شده به‌صورت زنده
- صفحه‌ی **درگاه پرداخت کاملاً آزمایشی** (هیچ مبلغی کسر نمی‌شود) و ثبت سفارش
- ویرایش پروفایل (نام، ایمیل، تلفن، آدرس) و لیست سفارش‌ها

**پنل مدیریت (`/panel/`)** ویژه‌ی ادمین
- داشبورد: کل فروش، فروش امروز، تعداد سفارش‌ها، میانگین سفارش، تعداد کاربران، کاربران جدید، بازدید امروز / ۷ روز / کل، بازدیدکننده‌ی یکتا، آنلاین‌ها، نمودار فروش و بازدید، پرفروش‌ترین‌ها
- مدیریت (افزودن، ویرایش، حذف، جستجو): کاربران، دسته‌بندی‌ها، محصولات، بنرها (عکس، عنوان، متن و مقصد دکمه) و سفارش‌ها
- گزارش بازدیدها و **فعالیت کاربران** (ورود، ثبت‌نام، سبد خرید، پرداخت و ...)
- پنل پیش‌فرض جنگو هم در `/admin/` در دسترس است

## 🚀 نصب و اجرا

پیش‌نیاز: **Python 3.10 یا بالاتر**

```bash
# ۱) (پیشنهادی) ساخت محیط مجازی
python -m venv venv
venv\Scripts\activate          # ویندوز
source venv/bin/activate       # لینوکس / مک

# ۲) نصب وابستگی‌ها
pip install -r requirements.txt

# ۳) ساخت دیتابیس
python manage.py migrate

# ۴) داده‌ی نمونه + حساب ادمین
python manage.py seed

# ۵) اجرا
python manage.py runserver
```

بعد این آدرس‌ها را باز کن:

| بخش | آدرس |
|---|---|
| فروشگاه | http://127.0.0.1:8000/ |
| پنل مدیریت | http://127.0.0.1:8000/panel/ |
| پنل پیش‌فرض جنگو | http://127.0.0.1:8000/admin/ |

> برای بارگذاری فونت‌ها، آیکون‌ها و انیمیشن‌ها به اینترنت نیاز است (CDN).

### حساب‌های پیش‌فرض (فقط برای تست)

| نقش | ایمیل | رمز |
|---|---|---|
| ادمین | `admin@gmai.com` | `Admin` |
| کاربر نمونه | `demo@example.com` | `demo1234` |

⚠️ **قبل از انتشار روی اینترنت حتماً رمز ادمین را عوض کن** و کاربر نمونه را حذف کن:
```bash
python manage.py changepassword admin@gmai.com
```
ایمیل و رمز اولیه‌ی ادمین در `store/management/commands/create_admin.py` تعریف شده است.

### داده‌ی نمونه برای نمودارهای داشبورد
```bash
python manage.py seed --fake-stats
```
این دستور سفارش، بازدید و فعالیت ساختگی می‌سازد. فقط برای تست محلی است و **روی سایت واقعی اجرایش نکن**.

## 🧭 راهنمای استفاده

- **افزودن محصول و دسته‌بندی:** پنل، بخش دسته‌بندی‌ها یا محصولات، دکمه‌ی «افزودن». نام و توضیحات را برای هر دو زبان پر کن
- **تغییر بنر:** پنل، بخش بنرها. عکس (پیشنهاد ۱۶۰۰×۶۰۰ پیکسل)، عنوان، متن دکمه و مقصد دکمه قابل تغییر است
- **ادمین کردن یک کاربر:** پنل، بخش کاربران، ویرایش، گزینه‌ی «دسترسی ادمین»
- **تغییر متن‌های سایت:** فایل `store/i18n.py` (هر کلید یک متن فارسی و یک متن انگلیسی دارد)
- **تغییر رنگ‌ها:** متغیرهای ابتدای `static/css/style.css` (`[data-theme="dark"]` و `[data-theme="light"]`)
- **پرداخت:** کاملاً آزمایشی است (`gateway` در `store/views.py`). برای درگاه واقعی باید با درگاه پرداخت دلخواه یکپارچه شود

## 🌐 انتشار روی هاست

برای انتشار روی هاست مثل PythonAnywhere، انتهای `shop/settings.py` این کد را اضافه کن تا فقط روی سرور فعال شود:

```python
import os
STATIC_ROOT = BASE_DIR / "staticfiles"
if os.environ.get("SHOP_PRODUCTION"):
    DEBUG = False
    SECRET_KEY = os.environ["SECRET_KEY"]
    ALLOWED_HOSTS = [os.environ["SITE_HOST"]]
    CSRF_TRUSTED_ORIGINS = ["https://" + os.environ["SITE_HOST"]]
    SECURE_PROXY_SSL_HEADER = ("HTTP_X_FORWARDED_PROTO", "https")
    SESSION_COOKIE_SECURE = True
    CSRF_COOKIE_SECURE = True
```

روی سرور:
```bash
python manage.py migrate
python manage.py create_admin       # یا seed برای داده‌ی نمونه
python manage.py changepassword admin@gmai.com
python manage.py collectstatic
```

نکته‌ها:
- فایل‌های `/static/` (پوشه‌ی `staticfiles`) و `/media/` (عکس‌های آپلودی) را در تنظیمات هاست به پوشه‌ی مربوطه وصل کن
- فایل `db.sqlite3` و پوشه‌ی `media` تستی را آپلود نکن
- هیچ‌وقت `DEBUG = True` را روی اینترنت نگذار و `SECRET_KEY` را عمومی نکن

## 🛠️ رفع مشکلات رایج

| مشکل | راه‌حل |
|---|---|
| `NodeNotFoundError` هنگام `migrate` | فایل‌های migration ناهماهنگ‌اند. فایل ناسازگار را پاک کن و `python manage.py makemigrations store` و بعد `migrate` را بزن |
| `/panel/` خطای 404 می‌دهد | سرور قدیمی هنوز باز است یا فایل‌های پروژه قدیمی‌اند. همه‌ی ترمینال‌های `runserver` را ببند و دوباره اجرا کن |
| `/panel/` خطای 403 می‌دهد | با حساب ادمین وارد نشده‌ای. خارج شو و با ایمیل ادمین وارد شو |
| ورود با ادمین کار نمی‌کند | `python manage.py create_admin` را بزن |
| نصب `pip` تایم‌اوت می‌دهد | `pip install -r requirements.txt --default-timeout=120 --retries 10` |
| فونت یا آیکون‌ها نمایش داده نمی‌شوند | اتصال اینترنت (CDN) را بررسی کن |
